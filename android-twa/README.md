# Present Android App (TWA)

This directory contains the Android wrapper for the Present PWA using Trusted Web Activity.

## What is TWA?
A Trusted Web Activity lets you package your PWA as an Android app with:
- Play Store distribution
- Native notifications
- Camera/file access
- No visible browser UI
- Full screen experience

## Structure
- `/app` - Android app module
- `/gradle` - Build configuration
- `bubblewrap.json` - PWA configuration
